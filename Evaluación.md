# Talleres – Deep Learning (SI7011)

Este repositorio contiene los talleres prácticos del curso de **Deep Learning**, cubriendo los principales paradigmas: redes densas, convolucionales, recurrentes y transformers.

## Talleres

### Taller 1 – Deep Neural Networks (DNNs)
🔗 https://www.kaggle.com/code/juanmartinezv4399/si7011-dl-mlp-pytorch  

Implementación de **redes neuronales densas (MLP)** en PyTorch.  
Se trabaja la transición desde regresión logística hacia redes profundas.

### Taller 2 – Convolutional Neural Networks (CNNs)
🔗 https://www.kaggle.com/code/juanmartinezv4399/si7011-tinyimagenetcompetition  

Aplicación de **redes convolucionales** para clasificación de imágenes en Tiny ImageNet.  
Se enfoca en el aprendizaje de representaciones espaciales.

### Taller 3 – RNNs para series de tiempo
🔗 https://github.com/jdmartinev/SI7011-DeepLearning/tree/main/Lecture05/notebooks/excercise  

Implementación de **RNNs/LSTMs** para modelar dependencias temporales en datos secuenciales.

### Taller 4 – Transformers para NLP
🔗 https://github.com/jdmartinev/SI7011-DeepLearning/tree/main/Lecture06/notebooks/excercise  

Uso de **Transformers** para tareas de procesamiento de lenguaje natural.

## Entrega

- Se debe entregar **un único repositorio de GitHub** que contenga todos los talleres.
- El repositorio debe incluir:
  - Notebooks de cada taller
  - Todos los notebooks deben estar ejecutados (con outputs visibles)
