Este ejercicio está dividido en dos partes y tiene como objetivo construir un modelo de deep learning para trabajar con **series de tiempo** utilizando redes neuronales recurrentes.

## Estructura

### Parte 1 – Procesamiento de datos
Notebook: `part-1-data.ipynb`

En esta sección se realiza:
- Carga y exploración de los datos
- Preprocesamiento de la serie de tiempo
- Construcción de ventanas temporales (secuencias)
- Preparación de los datos para entrenamiento

El objetivo es transformar los datos crudos en un formato adecuado para modelos secuenciales.

### Parte 2 – Modelado
Notebook: `part-2-model.ipynb`

En esta sección se implementa:
- Definición del modelo (RNN/LSTM)
- Entrenamiento del modelo
- Evaluación del desempeño
- Análisis de resultados

El objetivo es aprender dependencias temporales y realizar predicciones sobre la serie.

## Objetivo general

Construir un pipeline completo que vaya desde el procesamiento de datos hasta el entrenamiento de un modelo recurrente para series de tiempo.
